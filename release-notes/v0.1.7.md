## 下载

- **Windows 10/11 x64**：`Chartelis_0.1.7_x64-setup.exe`
- **macOS 12+（Apple Silicon / Intel 通用版）**：`Chartelis_0.1.7_universal.dmg`
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

## 本次更新

- 顶栏改为覆盖式布局，正文与源码可滚动到顶栏下方，不再由独立顶栏压缩内容区。
- 顶栏高度增加至 64 px，采用非线性透明渐变：顶部保持较高不透明度，向底部逐渐淡出至完全透明；适配亮色、暗色及其他配色。
- 设置新增「正文最大宽度」，可在 600–2000 px 间调整，默认宽度由 720 px 放宽至 960 px。正文随窗口自适应，达到上限后保持居中，并自动保存偏好。
- PDF、PNG 导出同步使用所选正文宽度；调整搜索框、AI 面板、选区工具栏与大纲的位置，避免被覆盖式顶栏遮挡。
- 同步调整 Windows 窗口控制区域与 macOS 原生红黄绿按钮位置，保留顶栏收起、展开和窗口拖动功能。

## 测试说明

继续提供未签名测试包：Windows 未进行商业代码签名；macOS 使用 ad-hoc 签名，未进行 Developer ID 签名与公证。

应用保留原有标识与本地工作区、设置。升级前请保存文稿并退出旧版。macOS 原生窗口按钮位置与拖动行为仍需真机验证。
