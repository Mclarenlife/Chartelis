## 下载

- **Windows 10/11 x64**：`Chartelis_0.1.8_x64-setup.exe`
- **macOS 12+（Apple Silicon / Intel 通用版）**：`Chartelis_0.1.8_universal.dmg`
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

## 本次更新

- 移除应用图标圆角外的白色背景，Windows 任务栏和 Mac Dock 使用带透明通道的图标；保留原有米白色圆角底板、C 字母、纸张图案与纹理。
- 更新 Windows ICO、Mac ICNS 和各尺寸 PNG，适配深浅背景；附上原始图标及可复现的本地轮廓裁切脚本。
- 微调覆盖式顶栏的非线性渐变：顶部降低不透明度，下半部分提高不透明度，最底边仍完全透明；保留正文从顶栏下方滚动的效果。

## 测试说明

继续提供未签名测试包：Windows 未进行商业代码签名；macOS 使用 ad-hoc 签名，未进行 Developer ID 签名与公证。

应用保留原有标识与本地工作区、设置。升级前请保存文稿并退出旧版。若系统仍显示旧图标，请退出应用后重新打开；已固定的任务栏或 Dock 图标可能需要移除后重新固定。
