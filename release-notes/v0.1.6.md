## 下载

- **Windows 10/11 x64**：`Chartelis_0.1.6_x64-setup.exe`
- **macOS 12+（Apple Silicon / Intel）**：`Chartelis_0.1.6_universal.dmg`
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

## 本次更新

- 顶栏移除软件 LOGO 和名称，Windows 窗口控制按钮与编辑工具共用一行；macOS 保留融入顶栏的原生红黄绿按钮。收起顶栏后仍可操作窗口。
- 新增 AI 助手：配置多个兼容 OpenAI Chat Completions 的 API，快速切换，流式显示 Markdown、表格、代码和公式；桌面版 API Key 保存在系统凭据库中。
- 设置新增 LaTeX 分隔符兼容开关，支持 `\(…\)` 和 `\[…\]`。正文、AI 回复与导出使用相同偏好，Word 中输出可编辑公式；切换不改写文稿或清空撤销历史。
- 新增简体中文、English、跟随系统语言选项；Windows 安装程序提供语言选择，macOS 首次启动可选语言。

## 测试说明

这是未签名测试版：Windows 未进行商业代码签名；macOS 使用 ad-hoc 签名，未进行 Developer ID 签名与公证。macOS 首次启动如被拦截，可在系统设置的「隐私与安全性」中对已确认来源的测试包选择「仍要打开」。

升级前建议备份重要文稿并退出正在运行的旧版。应用保留原有标识，继续使用本机工作区与设置。Mac 原生窗口行为、输入法与凭据库仍需真机测试，详见仓库的 MAC_TESTING.md。
